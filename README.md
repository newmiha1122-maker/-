# VUFC Букмекер — стартовый проект

Telegram-бот на Python + aiogram 3 + SQLite. В этой версии реализованы:
- регистрация и стартовый виртуальный баланс $0;
- карточки турниров и боёв с коэффициентами;
- создание одинарных виртуальных ставок и авторасчёт после внесения результата;
- история ставок, баланс, профиль, таблица лидеров;
- промокоды с наградой, лимитом активаций и сроком действия;
- защита от повторного использования промокода одним игроком;
- админ-панель для промокодов, турниров, боёв, результатов и виртуальных бонусов.

**Важно:** средства только виртуальные. Не подключайте денежные платежи или вывод денег.

## 1. Создайте бота
1. Откройте Telegram и найдите `@BotFather`.
2. Создайте бота командой `/newbot`.
3. Скопируйте токен. Не публикуйте его и не отправляйте в чаты.

## 2. Узнайте свой Telegram ID
Используйте бота `@userinfobot` или аналогичный способ, которому доверяете.
Ваш ID указывается в `ADMIN_IDS`, например `ADMIN_IDS=123456789`.
Для нескольких администраторов: `ADMIN_IDS=123456789,987654321`.

## 3. Локальный запуск
Python 3.11+:
```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
```
Скопируйте `.env.example` в `.env`, заполните значения и экспортируйте их в окружение.
Сам проект не загружает `.env` автоматически; для локального запуска переменные нужно задать в терминале или добавить `python-dotenv` и `load_dotenv()`.

Пример PowerShell:
```powershell
$env:BOT_TOKEN="ваш_токен"
$env:ADMIN_IDS="ваш_telegram_id"
python main.py
```

## 4. Railway
1. Загрузите файлы проекта в GitHub.
2. Создайте проект Railway из репозитория.
3. В Variables добавьте `BOT_TOKEN` и `ADMIN_IDS`.
4. Start Command: `python main.py`.
5. Для сохранения SQLite между деплоями подключите Railway Volume и задайте `DB_PATH` в пути внутри подключённого volume, например `/data/vufc.sqlite3`.

## 5. Админка
Напишите боту `/admin`.
- «Создать промокод»: код → сумма виртуального бонуса → лимит активаций (0 = без лимита) → срок UTC (`YYYY-MM-DD HH:MM`) или `0`.
- «Промокоды и статистика»: список кодов, наград и числа использований.
- «Отключить промокод»: деактивирует выбранный код.
- «Создать турнир», «Добавить бой», «Внести результат».
- «Начислить бонус»: начисление виртуальных средств игроку по Telegram ID.

## Примечания
- Промокод можно активировать только один раз на пользователя.
- Регистр букв в коде не учитывается.
- Бот сейчас поддерживает одинарные ставки в пользовательском интерфейсе. Экспрессы 2–5 событий, ник бойца с отдельным выбором и полноценный расчёт отменённых боёв — следующий этап до публичного запуска.
- Прежде чем запускать на реальных пользователях, протестируйте коды, ставки и восстановление базы данных.
